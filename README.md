# 三元相图 · 数学分析与可解释推理平台

在原三维三元相图模拟器（液相面、初晶区、界线、不变点、不稳定化合物、截面、平衡冷却）的基础上，
升级为以**线性代数、解析几何、计算几何、热力学与优化**为主线的多页面科学分析平台：
相图不是一组要背的线和规则，而是由状态变量、坐标变换、守恒律、平衡与优化约束定义的数学对象。

> **数据声明**：全部体系为假想组元 A–B–C 的**示意参数**，不代表任何真实材料；"固溶体演示模型"为另行构造、明确标注的二元模型。

## 固溶体（新增）

固相除化学计量相外，还可以是**正规溶液固溶体**：`G_φ(y,T) = Σ yᵢ °Gᵢ^φ(T) + RT Σ y ln y + Σ Ωᵢⱼ yᵢ yⱼ`（°Gᵢ^φ 为组元 i 在该结构中的晶格稳定性）。

| 环节 | 化学计量体系（原有，精确闭式） | 含固溶体体系（新增） |
| --- | --- | --- |
| 饱和温度 T_s(x) | 闭式解 | 交替 `T ← A(y)/B(y)` 与 `y ← argmax_y[μᴸ·y − G_s(y)]` —— 对驱动力的牛顿迭代（包络定理），收敛时 y 即共轭固相成分 |
| 平衡 | 构造式候选状态取最小 | 网格线性规划（对偶 = 公切面）→ KKT 牛顿精化（成分取 softmax 对数比参数）→ 加 / 去相迭代；冷却、截面中热启动 |
| 等温截面 | 扇形 + 连结三角形的精确几何 | 各相自由能面的**下凸包**（增量三维凸包）；三相三角形用精确解替换顶点；相界分辨率约 1/64 |
| 垂直截面 | 预知断点 | 逐行取样 + 二分定位相界 |
| 拓扑（界线、不变点、反应式） | 固定固相成分 | 用共轭固相成分（不变点记录 `solidX`），切线规则、Alkemade 检验同样改用共轭成分 |

新增体系：**有限固溶度三元共晶**（α、β、γ 端际固溶体；弯曲的初晶路径、固态脱溶）与**三元匀晶**（连续固溶体；Rachford–Rice 解析解作参照）。
新增验证算例 9（Rachford–Rice）与 10（移动端点的杠杆规则、背向线规则失效的量化、E 点共轭成分的化学势相等）。

## 热力学模型（`src/core/thermo.ts`）

能量基准为纯固相组元；所有量按"每摩尔原子（单元）"计。

```
液相   G_L(x,T) = Σ xᵢ ΔHᵢ(1 − T/Tmᵢ) + R T Σ xᵢ ln xᵢ + G_ex,   G_ex = Σ_{i<j} Ωᵢⱼ xᵢ xⱼ
固相   G_s(T)   = ΔHf − T ΔSf          （纯组元为 0；化合物为化学计量、互不溶）
```

液相与化学计量固相 s（组成 n）饱和的条件 `Σ nᵢ μᵢᴸ = G_s` 有闭式解：

```
T_s(x) = (Hs + Σ nᵢ μᵢᴱˣ) / (Ss − R Σ nᵢ ln xᵢ)
Hs = Σ nᵢΔHᵢ − ΔHf,   Ss = Σ nᵢΔHᵢ/Tmᵢ − ΔSf,   且  T < T_s(x) ⇔ 液相对 s 过饱和
```

- **液相面** = max_s T_s(x)，初晶相 = 取最大者的 s。
- **不稳定化合物**：化合物成分点处，别的固相的液相线高于它自身的 T_s(x_s) → 成分点不在自身初晶区内。
  判据与"假想熔点 / 实际液相线"在三维中同时标出。
- **界线**由 T_a = T_b 的栅格交点精确细化后连成折线；每段按 `L·dx_L = −Σ dnₛ(xₛ − x_L)`
  判定共晶型（单箭头）或转熔型（双箭头，并给出被回溶相）；温度极大点自动标出。
- **不变点**由 T_a = T_b = T_c 的牛顿迭代求得，反应式由质量守恒的零向量给出，
  按被消耗固相数分为 共晶（L → α+β+γ）/ 过渡点（L+α ⇌ β+γ）/ 包晶点（L+α+β ⇌ γ）。
- **相律**：凝聚体系恒压 F = C − P + 1 = 4 − P，在状态卡片与相区说明中显示。

## 交互

- **三维**：左键旋转、滚轮缩放、右键平移；工具栏：默认 / 俯视（即液相面投影）/ 正视 / 侧视 / 正对截面、剖切、截图。
- **等温面**：上下拖动水平面或蓝色球改变温度；平面本身显示该温度的等温截面（含连结线、连结三角形）；单击取点。
- **垂直截面**：拖动深蓝色截面平移，拖动端点（沿三角形周界）旋转；左栏可切换"平行边 / 过顶点 / 过状态点 / 化合物连线"；单击截面取点（成分 + 温度）。
- **状态点**：拖动红色球改变总成分；左栏滑块 / 数值输入；二维等温截面 / 液相面投影中单击拖动。
- **冷却**：底部栏播放、单步到事件、拖动曲线；不变反应平台内自动放慢，三维中实时显示液相点、固相点与连结线/三角形、结晶路径。
- **典型成分**：一键载入并播放，结论由测试保证与引擎一致。

## 原模型的一致性测试（`tests/core.test.ts`、`tests/fuzz.test.ts`）

- `T_s` 闭式解与化学势平衡 `Σ nᵢ μᵢᴸ = G_s` 一致；
- 平衡态质量守恒、相分数非负、相律成立；共存液相对共存固相饱和、对其余固相不过饱和；
- 三相状态满足**切平面最优性证书**（所有其它固相与液相均位于公切面之上）；
- 不变点三固相饱和温度相等，反应式满足质量守恒；
- 等温截面多边形、垂直截面栅格与逐点平衡一致；
- 冷却：相分数守恒、液相单调不增、终态为全固；
- 预设体系的拓扑断言（不稳定化合物的包晶点 / 过渡点 / 转熔线、稳定化合物的温度极大点）；
- 典型成分的结晶终态；随机参数扫描下不抛错且保持自洽。

## 已知限制

- 固相为化学计量相或正规溶液固溶体（二元相互作用项，无三元项）；液相为正规溶液，构造式求解器不支持液-液不混溶（固溶体求解器与 LP 支持）。
- 含固溶体时等温截面的相界为网格下凸包（约 1/64 分辨率），逐点平衡与相分数为精确解；垂直截面计算约 0.5 s，拖动三维截面时会有延迟。
- 三维场景中不单独绘制固相面 / 溶解度面，可通过等温面与垂直面观察。
- 各相共用同一热容 Cp（仅用于冷却时间轴），ΔCp = 0。
- 平衡冷却（无过冷、无偏析）；非平衡（Scheil）凝固未实现。
- 接入真实体系可由 CALPHAD 离线计算 (x, T) 网格上的平衡相组成，替换 `Thermo` 与 `PhaseDiagram.equilibrium`。
